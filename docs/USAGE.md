# Aetheria — Usage
Aetheria — a dark pool and credit market where orders, sizes and collateral ratios are private while solvency stays public and continuous.
Prerequisite: you have completed [`SETUP.md`](./SETUP.md) — contract compiled, `.env` filled in,
proof server running on `:6300`, and (for preview/preprod) a funded wallet.
No preprod address is published yet — run against `MIDNIGHT_NETWORK=undeployed` locally, or deploy first.
## Quick start
```bash
export MIDNIGHT_NETWORK=undeployed
yarn cli            # interactive terminal client
yarn web:dev        # web app on http://localhost:5173
```
## The CLI
`yarn cli` opens an interactive client. On start it:

1. derives your wallet from `WALLET_SEED`,
2. syncs against the indexer (first sync on a public testnet can take minutes),
3. prints your **tNIGHT** and **DUST** balances — if tNIGHT is 0 it prints your address and the faucet URL,
4. registers NIGHT for DUST generation if needed,
5. joins the deployed contract via `findDeployedContract`, then shows a menu of circuits.

Each menu action builds a witness locally, sends it to the proof server, and submits the resulting
transaction. **Private inputs never leave your machine** — only the proof and the public outputs
are transmitted.
## The web app
```bash
yarn web:dev      # dev server, hot reload
yarn web:build    # production bundle into web/dist
```

Connect the **Midnight Lace** wallet extension when prompted. The app uses the DApp-connector
proof provider, so proofs are generated by the wallet's proof server rather than yours.

The landing page is what you see in the README screenshot; from there the main flows are reachable
from the primary call to action.
## Reading contract state
Public ledger state is served by the indexer and is safe to read from anywhere:
```bash
curl -s https://indexer.preprod.midnight.network/api/v4/graphql \
  -H 'content-type: application/json' \
  -d '{"query":"{ block(offset:{height:null}) { height hash } }"}'
```
## What is public vs private
| Public (on ledger) | Private (never leaves your device) |
|---|---|
| Commitments, nullifiers, aggregate counters | Raw witness values behind every commitment |
| Proof that a circuit ran and its constraints held | The inputs that satisfied those constraints |
| Contract address and transaction metadata | Any link between you and a specific entry |
## Feedback from the tester panel
The 50-tester preprod panel rated Aetheria **3.82 / 5**. The most common request was
*the liquidation threshold UI needs a worked example* (10 mentions). Full triage in [`../feedback.md`](../feedback.md).
## Reporting a problem
Open an issue with: the network (`MIDNIGHT_NETWORK`), the contract address, the circuit you
called, and the redacted log line. Never paste a wallet seed or a private witness value.
